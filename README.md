Overview

This is a modern E-Commerce Web Application built using React + TypeScript, designed to simulate a real-world shopping experience.

It includes features like:

Product listing with infinite scroll
Search & filter
Cart management
Wishlist functionality
Checkout flow (in progress)

✨ Features
🏠 Home Page
Display products using API
Infinite scrolling for better UX
Category-based filtering
Debounced search
🛒 Cart
Add to cart
Increase / decrease quantity
Persistent cart using localStorage
Dynamic cart count
❤️ Wishlist
Add/remove products to wishlist
Stored in localStorage
Toast notifications for actions
🔍 Product Details
View detailed product info
Rating, description, pricing
💳 Checkout (In Progress)
Address form
Future integration:
Payment API
Location API (pincode autofill)

🧱 Tech Stack
Frontend: React + TypeScript
State Management: React Hooks
Routing: React Router
UI: Bootstrap / Custom CSS
Notifications: React Toastify
API: DummyJSON API


Installation & Setup
# Clone repo
git clone <your-repo-link>

# Install dependencies
npm install

# Run project
npm run dev
